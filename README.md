# ShopSphere – E-Commerce Website

## About
ShopSphere is an e-commerce website
where users can browse products and
shop online.

## Features
- Product Catalog
- Add to Cart
- User Login and Registration
- Shopping Cart
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Project Purpose
This project is developed to learn
full-stack web development.
